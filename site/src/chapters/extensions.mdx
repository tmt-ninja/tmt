Any program named `tmt-<name>` on your PATH becomes `tmt <name>`, the way components add commands to gcloud. Built-in commands always win, so an extension can't replace `talk` or `run`. Extensions reach tmt through its commands, JSON output and hooks, the same doors any other program uses.

<Cmd>{`
$ tmt ops ui           # runs tmt-ops ui
$ tmt help             # lists extensions it found
$ tmt ops sq <Tab>     # completion comes from the extension
`}</Cmd>

### Install, update and remove

The extensions below are installed the same way. Each one has its own version and updates on its own schedule. Removing one takes out its commands and skills and keeps its data.

<Cmd>{`
$ tmt extension install ops       # asks before changing anything
$ tmt extension ls                # what's installed and its version; --check looks for updates
$ tmt upgrade                     # CLI, skills and installed official extensions
$ tmt extension upgrade ops       # just Ops
$ tmt extension rm ops            # your data stays
`}</Cmd>

`tmt upgrade` also updates the official extensions you installed, each on its own channel and pin, and asks once for all of them; `--yes` skips the question. It also offers missing official extensions; one that fails does not undo completed updates. [Review the upgrade plan →](/working/settings#update-tmt) `tmt extension upgrade <name> --unpin` clears a pin.

A plain extension install does not publish agent skills. Add `--skills` to include the bundled skills in the installation you approve; there is no second skill question. To write your own extension, see [Build an extension](/develop/extensions). Any `tmt-<name>` on your PATH works without `tmt extension`.

### A command whose extension is missing

If you run an absent official command such as `tmt ops ui` in a human terminal, tmt explains which extension supplies it and asks **Install it now [Y/n]**. The offer includes bundled agent skills. Accepting installs it, then prints **Run it again:** with your original command; it does not run that command for you. Declining changes nothing. Help requests, JSON, pipes and agent invocations do not offer an interactive install; they return the missing-extension error and an explicit installation command instead.
