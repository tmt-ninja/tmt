<Mdx.h3 id="what-it-is">它是什麼</Mdx.h3>

團隊共用的一頁。lead 把計畫、筆記與決定放在這裡；agent 從指令列發布與更新頁面，大家則在瀏覽器裡閱讀、留言與做決定。不論 agent 在哪裡執行，所有人看到的都是同一頁。

Work 有 **Home** 與 **List** 兩個分頁。Home 預設使用 **Pages only**，顯示具有目前工作摘要的使用中頁面。**To-dos only** 顯示已指派負責人或等待擁有者回答的未完成編號待辦事項，等待擁有者的排在前面。List 用來瀏覽與篩選頁面，**All pages** 也會開啟它。點選頁面標題列中的工作編號即可複製編號。

寬螢幕上可以收合側邊選單，瀏覽器會記住這個選擇。頁面有大綱時，選單收合後仍保留一個窄大綱列。

<Mdx.h3 id="how-a-browser-reaches-an-agent">瀏覽器如何連到 agent</Mdx.h3>

Colab 作為本機服務執行，透過 Remote 掛載。瀏覽器經由該入口連線；向 agent 傳送訊息需要擁有者授予傳送權限。Remote 將請求交給本機 agent，再傳回與 receipt 綁定的回覆。暫緩的傳送須等待本機核准，狀態不確定的傳送不得自動重複。

<Mdx.h3 id="where-it-runs">在哪裡執行</Mdx.h3>

執行 `tmt colab serve`，在背景啟動本機 space。它會連接已執行的 Remote door，或啟動一個。指令會顯示 space 連結；`tmt colab stop` 停止該 space。頁面內容以加密形式儲存在本機。

瀏覽器配對與 Firestore 部署由 [Remote](/extensions/remote) 負責。配對、分享與傳送權限是分別作出的選擇，由機器擁有者決定。
