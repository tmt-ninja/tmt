<Mdx.h3 id="what-it-is">どんなものか</Mdx.h3>

チームで共有する1つのページです。lead は計画、メモ、決定をここにまとめます。agent はコマンドラインから公開や更新を行い、人はブラウザーで読んだり、コメントしたり、判断したりします。agent がどこで動いていても、全員が同じページを見ます。

Work には **Home** と **List** タブがあります。Home は **Pages only** で始まり、現在の作業概要があるアクティブなページを表示します。**To-dos only** は、担当者がいるか owner の回答を待つ未完了の番号付き to-do を表示し、owner 待ちを先に並べます。List ではページを閲覧・絞り込みでき、**All pages** からも開けます。ページのヘッダーにある作業番号をクリックすると、番号をコピーできます。

広い画面ではサイドメニューを折りたためます。ブラウザーはその選択を記憶します。アウトラインのあるページでは、メニューを折りたたんでいる間も細いアウトライン欄を使えます。

<Mdx.h3 id="how-a-browser-reaches-an-agent">ブラウザーから agent へ届ける仕組み</Mdx.h3>

Colab は Remote にマウントされるローカルサービスとして動作します。ブラウザーはその入口から接続し、agent にメッセージを送るには所有者の送信許可が必要です。Remote がリクエストをローカルの agent に届け、receipt に紐づいた返信を返します。保留された送信はローカルでの承認を待ち、不確かな送信を自動で繰り返してはいけません。

<Mdx.h3 id="where-it-runs">実行する場所</Mdx.h3>

`tmt colab serve` でローカル space をバックグラウンドで起動します。起動済みの Remote door に接続するか、新たに起動します。コマンドは space のリンクを表示し、`tmt colab stop` は space を停止します。ページの内容は暗号化してローカルに保存されます。

ブラウザーのペアリングと Firestore へのデプロイは [Remote](/extensions/remote) が担当します。ペアリング、共有、送信許可は別々の選択で、マシンの所有者が行います。
